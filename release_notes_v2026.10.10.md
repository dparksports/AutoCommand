# AutoCommand v2026.10.10

Self-contained Windows build — **no .NET installation required**. Unzip and run `AutoCommand.exe` as Administrator.

## Highlights

- **🧭 New: Sysmon Audit tab** — one status card answers "is Sysmon installed, healthy, and actually recording?" (service state, event-channel health, events per 24 h, active config hash), with Install, guided Repair, and Apply-Config buttons that handle half-installed leftovers automatically. The recommended configuration now captures **process creations (ID 1, with full command line and parent), network connections (ID 3) and DNS queries (ID 22)** — previously network-only — and can be applied to an existing install without reinstalling. A live process-creation feed with historical backfill makes short-lived processes attributable hours after they exit: the "mystery PID" question becomes a one-row lookup.
- **❄ New: Update Control tab** — pin a self-updating app at the version that works. Discovery finds candidates (self-update `.old` leftovers, updater folders, autostart updaters) with vendor signatures; freezing snapshots the file's exact permissions (`icacls /save`) and then denies delete/write on the executable, so the app keeps running while its updater fails politely until you unfreeze — which restores the original ACL exactly. Windows-signed system binaries are refused outright. Every freeze is recorded in `update_freeze.json`.
- **📊 New: Telemetry Opt-Out tab** — a knowledge base of known telemetry senders (Ultralytics YOLO's Google-Analytics beacon, .NET CLI, PowerShell 7, VS Code, Edge, Chrome, Windows diagnostic data) scanned against what's installed. Each row shows the on/off state with evidence, applies the **vendor's own documented opt-out** (settings key, environment variable, or policy — never a firewall hack), snapshots the previous value for one-click revert, and verifies via the DNS resolver cache that the beacons actually stopped. The rules ship in `Assets/telemetry_rules.json`, updatable without a rebuild.
- **🔍 Sharper Process Monitor attribution** — taskhostw rows for COM-handler scheduled tasks now show **which DLL actually runs** (ClassId resolved through `HKCR\CLSID\{…}\InprocServer32`) and flag tasks whose handler DLL is no longer registered — the classic leftover of uninstalled software.
- **🎨 Corporate rebrand** — the README and its infographic set were rebuilt from scratch in a light navy/blue corporate theme (generated by `Assets/generate_infographics_corporate.py`); the neon look is gone.
